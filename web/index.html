Set up Stremio or Fusion

Use the live addon link from this page for Will’s published recommendations. Get the latest Stremio release offered for your device through Stremio downloads. If you already use Fusion Media Center, follow the Fusion steps below.

  • Samsung / Tizen: install or update Stremio in the TV’s Apps store. Stremio lists support for Samsung models from 2019 onward; availability depends on your TV and store.
  • Google TV: install or update Stremio for Android TV from Google Play on the TV.
  • Apple TV: if Fusion Media Center is already installed, add the addon and Home widgets below. A current fresh-install download could not be verified; check Fusion’s official site for availability.
  • Computer: choose the current Stremio download for your operating system and processor. An existing Fusion installation on Mac can also use the addon.
  1. Stremio: on your computer, select Install in Stremio, then confirm in the app. If the app does not open, select Copy addon URL and paste it into Stremio’s addon search. Sign into the same Stremio account on your Samsung and Google TV, reopen the app, and check for Mood Engine · Will.
  2. Fusion: select Copy addon URL. In Fusion, open Settings → Addons, add the URL and enable the addon.
  3. Fusion Home: open Settings → Widgets, add a widget, then choose an external catalogue from Mood Engine · Will. Repeat for the rows you want on Home. Setting names may vary by app version.

Check that the addon is Mood Engine · Will. If you already have it, check its URL before adding another copy. Use Fusion’s Addons screen for the URL; Import Widgets expects a widget export file.
